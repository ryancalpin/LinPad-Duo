Install on this iPhone
  1. Open this page in Safari on the phone and tap Install. It's about 600 MB, so use Wi-Fi.
  2. Watch the Home Screen: the LinPad Duo icon fills up as it downloads.
  3. The first time: Settings › Privacy & Security › Developer Mode on, then restart.
  4. Open LinPad Duo and leave it open while it unpacks Linux (a few minutes).

Only works on iPhones registered in your Apple Developer account before this build ran. If Install does nothing, register the phone and build again.
